# My Book Store Project
At the university, I have been tasked to create book store managment for my project. In this project, I focused on building the GUI (Graphical User Interface) and then building the core for the GUI. I have made sure that book store managment works without any errors.

# Technolgy
> Python

# Features
- To be able to add books to the inventory
- Customers can register for the bookstore
- To be able to add/remove books to the basket

# The Process
I started by reading the requirements for the Book Store management. Then, I focused on what needs to be built first. I started with the GUI, so it will allow me to place the buttons and tables in the correct positions by using the grid method. 

Next, once I have learnt use the grid system in GUI, I have built each interface with tables and buttons. This was very important as the placement needed to be correct and also needed to have space from the buttons that would be on the left.

To make sure that the program doesn't run into any errors while using the interface, I have used loops function to raise any errors to the customer so it will remove any data that was inpuuted incorrectly.

Finally, I have built the core of the program. I've made sure that the core has reflection with the GUI, and also that the functions work properly. In the core part of the program i've used multiple techniques like encapsulation, property and setters, importing files into the GUI, and inheritance

Along the way, I had a few issues here and there with the code as I was changing one thing, and something else was breaking, even though I still found ways to fix but it took me a little longer.

This way, I understood that coding takes time to build and fix errors along the way. I documented my Python tasks; this helps me to reflect on myself and what could have gone better. I think it's a good practice to follow a guide when learning something new.
